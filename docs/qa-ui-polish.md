### 화면 확인 (에뮬레이터, QA 계정의 방을 열어 보기만 함)

- 공개방(public3, 방장): `< public3 [🌐 공개] ⋮`, 메뉴 = 방 설정·멤버 관리·방 나가기·방 삭제(빨강), 멤버 관리 창 = 멤버마다 방장 위임·내보내기(빨강)·닫기.
- 우리만 방(private3, 방장): `[🔒 우리만]`, 메뉴에 코드 재발급 포함.
- 본문의 관리 버튼 줄과 멤버 관리 목록이 사라져 멤버 얼굴이 바로 위로 올라왔다.
